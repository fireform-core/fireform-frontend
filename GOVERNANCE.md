# FireForm Frontend — Governance

This repository follows the same governance model as the [main FireForm repository](https://github.com/fireform-core/FireForm).

For the full governance document, see [**GOVERNANCE.md in fireform-core/FireForm**](https://github.com/fireform-core/FireForm/blob/development/GOVERNANCE.md).

---

## Summary

FireForm uses three roles:

| Role | Responsibility | GitHub Permission |
| :--- | :--- | :--- |
| **Owner** | Strategic direction, organization administration | Organization Owner |
| **Maintainer** | Code review, merging PRs, releases, issue triage | `Maintain` |
| **Contributor** | Code, docs, bug reports, discussions | Fork → Pull Request |

## Contributing to this repository

1. Fork the repository.
2. Create a branch from `development`.
3. Make your changes and ensure lint and tests pass.
4. Open a pull request targeting `development`.
5. A Maintainer will review and merge it.

See [CONTRIBUTING.md](CONTRIBUTING.md) for detailed instructions.
